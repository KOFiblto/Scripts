These are two simple programms, that allow me to mount and dismount my VeraCrypt safes easier/faster


-- mount.bat ---
1) Edit the File to configure your safe Count, safe path's and safe PID's
2) Run (Double Click) and choose a number
 + The Script will automatically Mount to the Last available Drive-letter (Z: -> A:)


-- unmount.bat ---
1) Run (Double Click)
 + The Script automatically dismounts all VeraCrypt drives
