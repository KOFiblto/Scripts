WebUntis Live Sync

Connects directly to the official WebUntis JSON-RPC API to pull your timetable lessons and absence logs for the current school year.

Security Information:
Credentials are stored locally in your SQLite database. Your password is sent directly to the school server via standard HTTPS requests. No third-party servers are involved.

Populate Mock Data

Populate the local SQLite cache with rich synthetic school lessons and random absences (sick days, late arrivals) across the past 9 months.

Why use mock data?
Ideal for testing! It enables you to preview all analytics features, Chart.js visuals, and the GitHub contribution heatmap immediately without entering real credentials.

Sync Troubleshooting & API Permissions

1. Permission denied for fetching absences (error -8509):

Standard password logins for student accounts typically do not have permission to retrieve absences via the standard JSON-RPC API. To bypass this, you must retrieve your 16-character Mobile Access Key (OTP Secret) from the WebUntis web portal (go to Profile -> Data Access / Mobile Devices, enable access, and click 'Show key'). Then, edit your profile settings and enter this 16-character key as your Password/Key.

2. Server format:

Ensure the server URL is clean. Enter it as webuntis.grupet.at:8080 or server.webuntis.com. The sync code will automatically strip any leading protocol (https://) and trailing paths.
