🏎️ Forza AutoDrive Basics

Forza AutoDrive is a universal automation suite designed to help you loop races, Time Attacks, and drift tracks in Forza Horizon with automated gamepad inputs.

Execution Focus Modes:

  • Foreground Drive: Starts after a customizable countdown delay. You must click onto the Forza Horizon window during this delay so it is active. The application will send standard gamepad inputs to it.
  • Background Drive: Starts driving immediately. Requires setting up DisplayFusion so the game continues accepting inputs when minimised or running in the background.

Quick Start Checklist:

  1. Make sure your virtual gamepad emulator driver is installed.
  2. Setup your track profiles and register matching cars.
  3. Select your track/car setup in the Drive Console and click Start Autodrive.

🏁 How to Add Tracks

Tracks represent the map circuits or sprint zones you run in Forza. To register a track:

  1. Go to the Track Setups tab.
  2. On the left sidebar, click the green + Add button.
  3. Enter the Track Name (e.g. Horizon Baja Circuit).
  4. Select the Track Type:
    • Race: Normal circuit races that support automatic sequences (universal start, post-race menus, and AutoDrive menu toggles).
    • Time Attack: Runs where the car holds throttle. No automated D-pad inputs or start/stop menus are required.
    • Drift: Drift loop paths that utilize automated, timed E-Brake taps.
  5. Click Create Track. You can upload custom banners from your computer to identify it.

🚗 How to Add and Configure Cars

To use a specific car on a track, you must first add it to your global library and then attach it to the track profile:

Step 1: Add a Global Car Model

  1. Go to the Cars Manager tab.
  2. Click + New Car in the upper right.
  3. Type the exact name (e.g. Toyota Tacoma or Lotus Evija) and save.
  4. Upload a profile picture to easily identify this car in menus.

Step 2: Assign Car to Track

  1. Go to the Track Setups tab and click your desired Track on the sidebar.
  2. Click the green + Add Car button in the configuration form header.
  3. Choose the car model from the dropdown list.
  4. Set the expected lap/race time, average XP per run, and Credits (CR). Make sure to enter your custom **CR Multiplier (+0% to +100%)** so yields calculate correctly!
  5. Click **Save Profile Changes** to persist details.

🖥️ DisplayFusion Setup Guide

DisplayFusion enables you to drive background windows. Follow these steps to configure background driving:

  1. Download and install DisplayFusion.
  2. Open DisplayFusion settings and navigate to the Functions tab.
  3. Search for the function named "Prevent Window Deactivation".
  4. Assign a key binding to this function (e.g., Ctrl + Alt + F).
  5. Launch Forza Horizon, click the game window to select it, and hit your key combination. The window is now flagged to remain active when unfocused!
  6. Select Background Focus in the Drive Console start setup. You can now use your PC freely while Forza drives in the background.

🎮 Virtual Gamepad Emulator Installation

The automation engine communicates using a virtual Xbox 360 controller emulation layer called ViGEmBus. If missing, please follow this setup:

  1. Navigate to the releases page: GitHub Releases: ViGEmBus.
  2. Download the latest installer file (usually `ViGEmBus_Setup.exe`).
  3. Run the setup wizard, grant administrative privileges, and click through the prompt.
  4. Once setup is complete, restart this application. The gamepad error indicator will automatically clear.

⚙️ Xbox Gamepad Controls & Settings

This software emulates a physical **Xbox 360 Controller** connection. To ensure inputs route successfully in Forza Horizon:

Required Game Settings:

  • Controls Profile: Go to Forza Settings → **Controls** and ensure your active configuration is set to the default gamepad layout.
  • Key Mapping: Ensure keybind buttons match emulated roles. For example, if you mapped Anna to `DPAD_DOWN` or AutoDrive to `DPAD_LEFT` in the **Sequences & Keys** tab, those buttons must correspond to their default functions inside Forza's settings.
  • Steam Input Warning: If running through Steam, make sure Steam Input is disabled or set to default Xbox configuration so it doesn't block the virtual controller inputs.

ℹ️ Background Driving Guide

Run Forza Horizon in the background using DisplayFusion

By default, Windows locks gamepad input to the active foreground window. By setting up DisplayFusion, you can send virtual controller inputs to the game even while it runs in the background, allowing you to use your PC for other work!

DisplayFusion Setup:

  1. Download and install DisplayFusion (Free version works!).
  2. Open DisplayFusion settings and go to Functions.
  3. Find the function "Prevent Window Deactivation".
  4. Assign a key binding to this function (e.g. Ctrl + Alt + F).
  5. Launch Forza Horizon, select its window, and press your key combination. This window will now remain active even when unfocused!
  6. In our assistant startup options, select Background Focus. The script will start driving immediately without taking over your screen!

⚠️ Virtual Controller Driver Missing

ViGEmBus driver is required for gamepad emulation

The application could not initialize the virtual Xbox 360 controller because the ViGEmBus driver is missing or not running.

Simple Installation Guide:

  1. Go to the official release page:
    GitHub Releases: ViGEmBus
  2. Download the installer executable (e.g., ViGEmBus_Setup.exe).
  3. Run the setup file and follow the onscreen setup.
  4. Once finished, restart this application.
